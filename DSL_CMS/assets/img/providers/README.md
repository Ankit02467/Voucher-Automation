# Provider logos

Drop a logo here and the Voucher Status dashboard picks it up on the next page
load. No code change, no restart, no list to register it in.

Name the file after the provider, lowercased, with anything that is not a letter
or digit removed:

| Provider | File |
|---|---|
| AWS | `aws.png` |
| Microsoft | `microsoft.png` |
| PTE | `pte.png` |
| ETS | `ets.png` |
| LanguageCERT | `languagecert.png` |

`.png`, `.svg`, `.jpg`, `.jpeg` and `.webp` all work; they are looked for in that
order. A provider with no file here keeps the coloured initials tile, so a
missing logo never leaves a hole in the table.

The tile is 40x40 and the image is contained inside it on a white background, so
a wide or tall mark will not be cropped or stretched. Square-ish artwork with a
little padding of its own looks best. Transparent PNG or SVG is ideal.

Nothing is committed here yet - these are third party trademarks, so the files
have to come from you or from whatever the brands' own guidelines allow.
